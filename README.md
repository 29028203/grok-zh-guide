# Grok 中文指南

## Grok介绍

Grok 是马斯克旗下 xAI 公司研发的多模态大模型系列，依托 X 平台生态实现实时信息联动与高效生成，本仓库收录老手村 Grok 专区关于 Grok 的版本动态与资讯文章。Grok Imagine 1.0 是 xAI 推出的核心 AI 视频生成模型，主打极速生成与原生音画同步，可将文本、图像提示转化为流畅高清视频；Grok 对话模型则持续迭代，支持联网获取实时信息、在 X 生态内深度联动。

## Grok特点

- 原生音频智能匹配，音画同步精准。
- 生成速度行业领先，短时间输出完整视频。
- 依托 X 生态实时联动，紧跟热点。
- 文生视频/图生视频双模式，自然语言一键成片。
- 对话模型持续迭代，支持联网与实时信息。
