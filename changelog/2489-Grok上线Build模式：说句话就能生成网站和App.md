# Grok上线Build模式：说句话就能生成网站和App

> 原文链接：[https://www.laoshoucun.com/grokdt/2489](https://www.laoshoucun.com/grokdt/2489)

<p><a href="https://www.laoshoucun.com/grok" target="_blank" rel="noopener">Grok</a> 最近在 SuperGrok Heavy 订阅里加了一个 Build Mode，现阶段 Early Beta。输入需求之后，它在对话窗口里直接出预览，网页和应用都能生成，改界面和加字段都能在对话里继续完成，样式也能接着调，不过复杂的数据源对接和后端逻辑还是要自己写。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/08/20260817121107_766983.png" alt="Grok Build模式"></p>
<p>成品发布给了两个出口，一个是 grok.me 的短链接，另一个是绑定自定义域名，落地页和个人作品集是目前支持得比较好的场景，轻量工具也能做，游戏只有街机赛车和解谜这类小游戏模板，数据方向能接业务表出图表，不过后两类都还比较初级。</p>
<p>入口不宽，Heavy 档月费不低，Beta 阶段稳定性也没法保证，网页、iOS 和 Android 三端虽然都能进，但半成品状态不少见。xAI 把 Grok 从聊天工具往开发平台推了一步，GitHub Copilot、<a href="https://www.laoshoucun.com/claude" target="_blank" rel="noopener">Claude Code</a> 这些对手已经跑在前头，GPT 也在同一条赛道上，它现在属于追赶者。消息公布当天，SpaceX 股价盘中涨了 2.8%。</p>
<p>普通人拿它做什么。搭个页面验证想法和做内部小工具，速度是有的，真要对外发布，代码审查和工程流程一样不能少，后续维护也省不了。</p>
