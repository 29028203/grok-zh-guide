# Grok 4.6 上线 GitHub Copilot：八大开发环境可选，价格只要对手一半

> 原文链接：[https://www.laoshoucun.com/grokdt/2546](https://www.laoshoucun.com/grokdt/2546)

<p>8 月 14 日，xAI 官方和 GitHub 先后确认，<a href="https://www.laoshoucun.com/grok" target="_blank" rel="noopener">Grok</a> 4.6 开始向 Copilot 订阅用户分批开放，出现在 Grok 模型选择器里，此时距 4.6 发布刚过两天。从正式发布到进入全球装机量最大的编码助手，前后不到 72 小时。</p>
<p>铺开的范围不小。VS Code 和 Visual Studio 打头，Copilot CLI、云智能体和 Copilot 应用跟进，JetBrains 全家桶，Xcode 和 Eclipse 也没落下，八个开发环境一次到位。Copilot 上新模型历来先伺候 VS Code，这次 JetBrains、Xcode 和 Eclipse 同步跟进，意图很清楚，让 Grok 4.6 直接嵌进主流开发者的日常流程。</p>
<p><img decoding="async" src="https://cdn.laoshoucun.com/web/2026/08/20260818111704_362005.png" alt="Grok 4.6 接入 GitHub Copilot 编程场景" style="max-width:100%;height:auto;border-radius:8px;margin:16px 0"></p>
<h2>怎么开通：个人等推送，企业要管理员放行</h2>
<p>开通分两种。Copilot Pro、Pro+，Max，Business 和 Enterprise 五个档位全覆盖，个人用户什么都不用做，模型选择器滚到自己账号那天就能用。Business 和 Enterprise 走另一套逻辑，管理员得先在 Copilot 设置里把 Grok 4.6 的策略打开，默认状态是关闭，IT 不放行，员工的模型列表里压根看不到它。GitHub 内部测试的评价不低，VS Code 和 Copilot CLI 的终端类编码任务上表现强，特别是需要持续推理和反复调工具的长时程任务，正好踩在它的主场，与 xAI 给这代模型定下的为长时间运行的多步工作流而生，定位对上了。</p>
<h2>价格才是杀手锏</h2>
<p>价格是这轮最大的卖点。Copilot 里 Grok 4.6 按用量计费，每百万输入 token 2 美元，输出 6 美元，与 Grok 4.5 基础价持平。参照系摆在旁边：GPT-5.6 Sol 输入 5 美元，输出 30 美元，Claude Opus 级别是 5 美元和 25 美元。一对照，Grok 4.6 的定价只有对手的一半不到。性能数字也摊开看：CursorBench v3.2 拿 69.9%，压过 GPT-5.6 Sol 的 67.2%，略低于 Claude Fable 5 的 70.5%。Terminal-Bench v3.0 的 26% 落后 GPT-5.6 Sol 的 34.6%，但对比上一代 Grok 4.5 的 15.7% 接近翻倍。终端场景还在追赶，方向没跑偏。</p>
<p>分发不止这一条线。发布当天，Grok 4.6 就上了 xAI 自家的 Grok Build 和代码编辑器 Cursor，API 同步开门，OpenRouter、Vercel 和 Cloudflare 三家第三方平台紧随其后。首周庆祝活动也实在，Grok Build 和 Cursor 里的包含用量直接翻倍，8 月 19 日截止。这是 Grok 第二次进 Copilot，7 月 28 日 Grok 4.5 就集成过一回，但 4.6 这次的节奏罕见，公开亮相到进入 Copilot 生态，前后不到三天。对开发者的意义很朴素，模型列表里多一个能打又便宜的选项。尤其 Copilot 现在走多模型路线，OpenAI、Anthropic 和 Google 的模型和 Grok 并排摆着，谁顺手谁拉胯，自己跑一圈就有答案。</p>
